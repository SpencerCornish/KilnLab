# Self-hosted fonts

Kiln Control uses these fonts, self-hosted so the app works offline and under the
server's strict Content-Security-Policy (no external font hosts).

| File | Family | Weight | Subset |
|---|---|---|---|
| `barlow-400-*` | Barlow | 400 | latin, latin-ext |
| `barlow-500-*` | Barlow | 500 | latin, latin-ext |
| `barlow-condensed-500-*` | Barlow Condensed | 500 | latin, latin-ext |
| `barlow-condensed-600-*` | Barlow Condensed | 600 | latin, latin-ext |
| `share-tech-mono-400-latin.woff2` | Share Tech Mono | 400 | latin |

Source: [Google Fonts](https://fonts.google.com/). All three families are
licensed under the SIL Open Font License 1.1.
